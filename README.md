# Ofrenda Digital

Página interactiva de Día de Muertos: toma una foto de un objeto, la página recorta el fondo y lo coloca en una ofrenda ilustrada (calavera, velas, cempasúchil y papel picado).

- **Tomar foto / Subir imagen**: abre la cámara o la galería.
- **Recorte**: automático en el navegador; se ajusta con el deslizador "Quitar fondo" y el pincel (Borrar / Recuperar). Funciona mejor con fondo liso.
- **En la ofrenda**: arrastra, pellizca para escalar y girar, + / − y ↺ / ↻.
- **Guardar imagen**: descarga la ofrenda como PNG.

Los objetos se guardan solo en el navegador de cada persona (localStorage). No hay servidor ni se suben fotos.

Sitio: https://gusmerckel.github.io/ofrenda-digital/
